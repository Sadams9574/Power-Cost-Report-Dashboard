Jobs in the plan

How the workbook tells the dashboard what it is Sector: a cell reading Sector with Power, Pipeline or Facilities next to it. If there is none, the file name is used (for example Pipeline_Workforce.xlsm). You can also change it in the table above. Status and Win %: a cell reading Status (Awarded, Likely or Bidding) and a cell reading Win %, each with the value next to it. Crafts tab: a tab named Crafts with the craft in column A and its group in column B (for example Welder Helper | Welding & Pipefitting). Capacity tab: a tab named Capacity with craft in column A, headcount in column B, and optionally a sector in column C. Rows with no sector count company-wide.

Headcount on hand

People you have today (or can count on) in each craft. Leave blank if unknown; blank crafts are left out of the shortage math. Overall always uses company-wide numbers. A sector uses its own numbers once you enter any, otherwise company-wide.
