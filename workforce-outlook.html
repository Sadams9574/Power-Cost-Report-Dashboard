    Workbooks, jobs and manpower

    Load job workbooks, set sector and status, and enter headcount on hand.

    Add or refresh jobs from Excel

    Drop one or more .xlsm / .xlsx workforce workbooks here, from any sector. Every tab that has the “Craft … Total Crew” summary block becomes a job. Loading a job with the same name replaces it.

    Jobs in the plan

    How the workbook tells the dashboard what it is Sector: a cell reading Sector with Power, Pipeline or Facilities next to it. If there is none, the file name is used (for example Pipeline_Workforce.xlsm). You can also change it in the table above. Status and Win %: a cell reading Status (Awarded, Likely or Bidding) and a cell reading Win %, each with the value next to it. Crafts tab: a tab named Crafts with the craft in column A and its group in column B (for example Welder Helper | Welding & Pipefitting). Capacity tab: a tab named Capacity with craft in column A, headcount in column B, optionally a sector in column C and weeks to hire in column D. Rows with no sector count company-wide. Hiring Plan tab: a tab named Hiring Plan with craft in column A, the change in column B (+10 or −20), the starting month in column C, and optionally a sector in column D.

    Current manpower (actuals)

    People you have today (or can count on) in each craft. Leave blank if unknown; blank crafts are left out of the shortage math. Company-wide numbers count everywhere. A sector number, if you enter one, replaces the company-wide number for that craft on that sector's tab. You can also type actuals straight into the Actual column of the shortage grid.
    Paste current manpower from Excel
    Copy two columns from Excel (craft, then headcount) and paste them here. Applies to the “Headcount for” choice above.

    Planned hires and releases

    Changes to headcount from a month onward, for example +10 Journeyman Electricians from Mar '27, or −20 Laborers from Nov '27. They show when “With hiring plan” is selected. A sector change shows on that sector's tab and in Overall.
